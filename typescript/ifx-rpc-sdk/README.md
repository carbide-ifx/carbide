# @carbide-ifx/rpc-sdk

Protocol-neutral TypeScript runtime used by service SDKs generated by
`ifx.rpc.typescript.ksp`.

This package contains `IfxBinding`, the generated SDK constructor contract,
service descriptions, JSON serialization, headers, and outbound interceptors. It
does not contain a network protocol. Install one of the explicit protocol
packages alongside it:

- `@carbide-ifx/rpc-sdk-rsocket`
- `@carbide-ifx/rpc-sdk-jsonrpc`
- `@carbide-ifx/rpc-sdk-http`

Generated SDKs accept any `IfxBinding`, and expose a static service address
used by the protocol-specific connection factories:

```ts
import { RSocketSdk } from "@carbide-ifx/rpc-sdk-rsocket";
import { JsonRpcSdk } from "@carbide-ifx/rpc-sdk-jsonrpc";
import { IProductAccessSdk } from "./generated/IProductAccess";

const rsocket = await RSocketSdk.connect(IProductAccessSdk, "ws://localhost:7000");
const jsonRpc = await JsonRpcSdk.connect(IProductAccessSdk, "http://localhost:7001");
```

All protocol SDK entrypoints accept the same `headers` and `interceptors` options, so
cross-cutting message behavior is independent of the selected wire protocol.

## Development

```shell
cd typescript
npm ci
npm test --workspace @carbide-ifx/rpc-sdk
npm run test:generated
```
