# @ifx/rpc-client

TypeScript runtime used by clients generated by `ifx.rpc.typescript.ksp`.

The runtime is intentionally separate from generated service contracts. It owns
the RSocket WebSocket connection, IFX composite metadata, JSON serialization,
stream backpressure, cancellation, headers, and client interceptors.

The RSocket dependencies are pinned to `1.0.0-alpha.3`. This is the newest
published TypeScript API line, but it is still an upstream alpha.

## Usage

Install this package in the project that consumes generated contracts, then use
the generated client's `connect` factory:

```ts
import { ISalesManagerClient } from "./generated/ISalesManager";

const client = await ISalesManagerClient.connect("ws://localhost:8080", {
  headers: () => ({
    "ifx.context": {
      "example.caller": { subject: "user-42" },
    },
  }),
});

try {
  for await (const product of client.listProducts()) {
    console.log(product);
  }
} finally {
  client.close();
}
```

Browsers use the global `WebSocket` constructor. Other runtimes can supply a
compatible constructor through `wsCreator`.

## Interceptors

Interceptors wrap raw `IfxMessage` streams. They can transform request and
response headers or bodies and retain cancellation semantics for request
streams:

```ts
const client = await ISalesManagerClient.connect("ws://localhost:8080", {
  interceptors: [{
    async *intercept(call, next) {
      console.log(call.operation);
      yield* next(call);
    },
  }],
});
```
