# @ifx/rpc-client

Protocol-neutral TypeScript runtime used by service clients generated by
`ifx.rpc.typescript.ksp`.

This package contains `IfxBinding`, the generated-client constructor contract,
service descriptions, JSON serialization, headers, and client interceptors. It
does not contain a network protocol. Install one of the explicit protocol
packages alongside it:

- `@ifx/rpc-client-rsocket`
- `@ifx/rpc-client-jsonrpc`

Generated clients accept any `IfxBinding`, and expose a static service address
used by the protocol-specific connection factories:

```ts
import { RSocketClient } from "@ifx/rpc-client-rsocket";
import { JsonRpcClient } from "@ifx/rpc-client-jsonrpc";
import { IProductAccessClient } from "./generated/IProductAccess";

const rsocket = await RSocketClient.connect(IProductAccessClient, "ws://localhost:7000");
const jsonRpc = await JsonRpcClient.connect(IProductAccessClient, "http://localhost:7001");
```

Both protocol clients accept the same `headers` and `interceptors` options, so
cross-cutting message behavior is independent of the selected wire protocol.

## Development

```shell
cd typescript
npm ci
npm test --workspace @ifx/rpc-client
npm run test:generated
```
